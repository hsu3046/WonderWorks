### Webcrawler 다리 교차 교정

- 사용자 지적: 뒷다리가 교차해 여덟 다리 형태가 불명확함. 공용 IK 굽힘 부호가 rear knee를 몸통 반대편으로 6.7만큼 보내는 것이 원인.

## 2026-10-03 — Webcrawler 원본 디자인 보기

- 사용자 요청으로 본문 재구성의 낮은 재현도를 개선. 선택적 Playwright/Chromium으로 원본을 렌더링하고 계산된 스타일·이미지·폰트를 포함한 정적 DOM을 복제한다. 이전의 본문 전용 결정은 원본 보기와 자동 본문 fallback으로 확장됐다.
- 표시 iframe은 `allow-same-origin`만 허용하고 script·외부 요청·탐색을 차단한다. 원본 DOM을 감싸지 않는 Range + CSS Highlight로 단어를 숨겨 배치를 유지하며, 문자별 span도 하나의 단어로 묶는다. 입 3회 움직임 뒤 소멸하는 순서를 유지한다.
- `server/snapshot.mjs`는 기존 DNS 고정/공개 IPv4 전송을 재사용하며 2개 브라우저, 22초, 120요청, 동시 fetch 4개, 개별 3MiB/합계 16MiB로 제한한다. 로컬 `.env.local`에서 기존 Playwright를 지정했으며 새 설치·배포는 하지 않았다. gallery/배포 서버는 별도 동일 환경 설정이 필요하다.
- 전체 check/build, crawler 14개 단위 테스트, 기존 브라우저 12개/포식 4개/원본 복제 5개 그룹 통과. 실제 example.com·W3C 원본 보기를 확인했다. 자체 검증 페이지의 주요 위치 차이는 0.6px 이내; 모든 사이트의 동일 재현을 보장하는 수치가 아니다. 자세한 제한은 `docs/crawler/VALIDATION.md`.

### Webcrawler 랜덤 탐색

- `탐색 시작` 옆에 `랜덤`: 후보 187개를 실제 원본 렌더러로 검사해 36개 출처의 100개 페이지(한국어 19, 영문 81)를 선정. 1060×534 복제 화면에서 본문 가로 잘림·큰 고정 팝업·부분 캡처 표시가 없는 후보를 사용한다. 목록/기준은 `docs/crawler/RANDOM_PAGES.md`.
- `src/destinations.ts`의 URL·제목만 배포하고 본문·이미지는 저장하지 않는다. `src/random.ts`는 한 순회에서 중복 선택을 피하고 현재 페이지/입력 주소를 제외한다. 클릭 시 기존 단일 페이지 로더를 호출하며 후보 일괄 prefetch는 없다. 좁은 화면에는 주소 아래 두 버튼을 나란히 표시한다.
