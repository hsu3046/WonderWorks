# Setup

From projects/chroma: npm run dev (port 4176), npm run check, npm run build. Existing workspace node_modules is shared from ../fish/node_modules. For a standalone source download, run npm install locally before building. Do not include the supplied reference video in a public build.

After updating the study, build it and run the gallery's prepare:works script to refresh its static copy. Rerecord the gallery MP4 when the visual output changes. Card preview footage is in gallery/public/media/previews/chroma.mp4; interactive detail uses experiments/chroma/index.html?preview=1.
