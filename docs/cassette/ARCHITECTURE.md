# Cassette / Study 015

## Reference and scope

Public X post by @ann_nnng (status 2110345498028810390), a 20.3-second 1080×1350 recording inspected on 2026-10-14 at roughly two-second intervals through its browser video element, plus the author's shared TypingMind transcript describing the prompt. Observed: four AI-generated renders of a photographed pink translucent cassette on white, each auto-rotating through 360° with a rocking tilt, a holographic sheen washing pink → violet → blue across the printed front label, reels turning as if rewinding, a label-free clear pink back, and small transport controls. The recording, the source photograph and the generated code are not used; geometry, label artwork, shaders and interaction are original AIB work.

## Model

- `settings.ts` — pure state and reel mechanics. Tape transfer conserves pack area (`left² + right²` is constant); each reel's angular speed is tape speed ÷ its pack radius; the transport auto-reverses at either end; frame gaps are capped so a background tab cannot jump the tape. Title text is bounded and stripped of control characters before it reaches the canvas.
- `label.ts` — Canvas 2D label (1120×600): seeded stars, clouds, a ringed planet, title in a system script face, track lines and a side badge. Also the slip-sheet badge, pack-face grooves and the floor shadow gradient.
- `holo.ts` — GLSL for the label. The view direction is returned to label space; its xy tilt drives a palette phase. Saturated pink pixels drift toward violet/blue as the tilt grows, light pixels take a tint, a wide gloss band sweeps with the tilt, diagonal diffraction lines fade through `fwidth` when unresolvable, and two glitter scales change with the viewing angle. Output passes through Three's tone mapping and colour-space chunks.
- `cassette.ts` — procedural body at 4 × 2.54 × 0.48 units. Two extruded, bevelled translucent halves meet at a darker seam ring; the front half carries one wide window that encloses both hubs (holes never overlap, which would break triangulation), the back half carries hub holes only. Label and glass are flat shapes bonded just above the front face; the glass has hub holes so the toothed white hubs sit inside it. Tape packs are unit cylinders scaled per frame; ribbons run from each pack to bottom rollers and along the head opening. The slip sheet stays well inside the walls so the side view reads as one slab. Screws, head openings, pressure pad, back ribs and a side-B badge complete the shell.
- `viewer.ts` — renderer, lights, room environment, free rotation and lifecycle. Drag maps screen deltas to a world-space axis-angle premultiplied onto the orientation quaternion, so the surface follows the pointer like a globe; sensitivity is fixed per gesture from the stage width. Release keeps a decaying inertia; reset slerps back to the rest pose; automatic turning premultiplies a world-Y rotation and the rock/float ride on a parent group so they never fight the user's orientation. Touch yields vertical strokes to the page and cancels on a second pointer. The contact shadow scales with the rotated footprint. Rendering is continuous only while something moves; one frame is painted on demand even when the tab is hidden, and the loop pauses while hidden. Renderer, materials, textures and listeners are disposed on HMR.

## Validation

Unit tests (`npm run test --prefix projects/cassette`) cover pack-area conservation, inverse-radius reel speeds and direction, stop/invalid-dt stability, auto-reverse at both ends, frame-gap capping and title sanitising. Browser checks at desktop width: front/side/back/top views, keyboard turning and reset, drag with inertia, wheel zoom, transport and auto-reverse status messages, shell tints, title change, PNG save; 375 px layout without horizontal overflow; `prefers-reduced-motion` render without console errors. The gallery preview is a 6-second 1200×1200 canvas capture of the implemented scene via headless Chromium with Metal (the SwiftShader headless shell cannot create a WebGL context).
