# Koi Pond Garden — Stillwater 참고 코드 분석

조사일: 2026-09-30. 범위: 공개 화면·소스와 현재 `projects/pond` 비교. 이 문서는 제안이며 런타임 구현을 변경하지 않았다.

## 요약

가장 큰 시각적 개선 후보는 **수종별 수형, 높이가 다른 식물 군락, 자연스러운 물가 연결**이다. 이어서 가속·활주가 연결되는 물고기 움직임과 실제 깊이에 따른 물의 굴절을 적용할 가치가 있다. 기존 GLB 생물·건축물, 원래 물고기 색, 원경·지면 일러스트를 유지하면서 개선한다.

## 1. 나무와 식물: 가장 먼저 반영할 부분

원본의 식물은 내려받는 개별 GLB 에셋보다 **절차적 모델 생성 코드 + Canvas 텍스처 + 인스턴싱** 형태로 구성되어 있다. 필요한 생성 규칙을 모듈로 옮기거나, 정적인 형상·텍스처를 사전 생성하는 방식이 적합하다.

| 요소 | 원본에서 확인한 구현 | 현재 Stillwater에 적용할 방향 |
|---|---|---|
| 수종별 수형 | `growTree`의 가지 각도·중력·분기 단계가 수종별로 다름. 단풍은 물가로 기울고 소나무는 납작한 잎 덩어리가 층을 이룸 | 현재 `garden.ts`의 공통 `tree()`를 수종별 설정으로 구분. 잎 수를 늘리기 전에 실루엣과 가지 흐름 개선 |
| 벚꽃 | 일반 벚꽃과 수양벚꽃을 구분. 꽃이 가지 끝뿐 아니라 늘어진 가지를 따라 분포 | 현재 꽃 덩어리 사이를 연결하는 가는 가지·꽃줄기를 보강. 기존 벚꽃 위치와 규모는 기준으로 유지 |
| 관목 | 불투명한 낮은 덩어리 + 외곽의 잎 카드. 진달래·회양목·작은 군락을 혼합 | 현재 잎만 흩뿌린 관목에 내부 덩어리와 접지감을 부여. 동일 실루엣의 반복 완화 |
| 하층 식생 | 휘어진 고사리 잎, 넓은 무늬 잎, 부채꼴 붓꽃 잎, 작은 풀뭉치 | 물가·나무 아래·바위 틈에 종류별 군락으로 배치. 잔디의 균일한 띠를 부분적으로 대체 |
| 잎의 재질 | 살짝 오목한 카드, 알파 컷아웃, 종별 투광량, 바람 및 동일한 그림자 변형 | 가까운 잎은 기존 입체 형상, 중거리는 가지 단위 카드로 구분. 역광 투광과 음영을 먼저 조정 |
| 색과 규모 | 어두운 침엽수·중간 녹색 관목·밝은 풀·소량의 분홍/붉은 꽃이 공존 | 잎마다 무작위 색을 강하게 바꾸기보다 군락 단위 색을 통일하고 명도·형태 대비 확보 |

### 전체 분위기에 대한 해석

원본의 풍성함은 큰 나무 아래 빈 공간을 중간 높이 관목, 낮은 잎, 바위와 이끼가 이어 주는 구성에서 상당 부분 나온다. 현재는 동일한 잎 형상을 나무·관목·꽃에 재사용하고, 주 잔디만 78,000개 배치한다. **종류와 높이의 차이**를 확보하는 편이 단순 개수 증가보다 효과적일 가능성이 높다. 이는 소스와 화면을 토대로 한 미술 방향 제안이며 성능 개선량을 측정한 결론은 아니다.

권장 공간 구성:

1. 앞쪽: 물고기를 볼 수 있는 열린 물가와 낮은 식생.
2. 좌우: 물 쪽으로 기운 단풍·벚꽃, 고사리·붓꽃으로 화면을 감싸는 구성.
3. 중간: 관목과 어두운 수관으로 정자·다리의 밝은 면을 강조.
4. 원경: 기존 360도 숲 일러스트를 유지하고 가까운 입체 식생과 색·안개를 맞춤.

예상 적용 파일: `garden.ts`, `nature-materials.ts`, `meadow.ts`, `backdrop.ts`. 새 식물을 기존 잔디 위에 계속 추가하는 방식은 피하고 일부를 대체한다. 공간별로 인스턴스를 나눠 컬링할 수 있게 하되 드로콜 증가도 함께 측정한다. 알파 카드의 겹침과 그림자 패스가 비용을 키울 수 있으므로 가까운 군락부터 적용한다.

| 회피·먹이 | 비슷한 깊이의 이웃만 분리, 진행 방향 앞쪽 물가 검사, 실제 먹이 알갱이 추적 | 상하로 떨어진 물고기의 불필요한 회피 감소. 현재 공통 먹이 지점 대신 알갱이 접근·섭취 연결 |
| 잠자리 | 가는 분절 몸통, 종별 무늬, 앞뒤 날개 형태 차이, 투명한 막과 날개맥 | 기존 작은 크기 유지. 근접 시 날개맥·형상만 개선하고 화면에서 작은 개체의 계산은 단순하게 유지 |
| 개구리·수면 사건 | 도약·착수와 파문, 물방울·기포의 연결 | 기존 리깅된 개구리와 다리 동작 유지. 착수점에 짧은 물방울과 파문을 동시 발생 |

## 3. 물: 깊이와 렌더링 대상을 정확하게

- 현재도 Fresnel 반사와 Beer–Lambert 형태의 흡수가 있다. 부족한 것은 실제 깊이 입력이다. 원본은 굴절 타깃의 DepthTexture로 수면→물체의 거리를 계산하고, 그 길이에 맞춰 굴절·흡수를 변화시킨다. 물가 물체가 엉뚱하게 휘는 현상을 막는 깊이 검사도 있다. 기존 물고기 색이 다시 과하게 옅어지지 않도록 흡수 계수는 별도로 조정해야 한다.
- 원본은 수상·수중·수면·경계 교차 물체를 레이어로 나눠 패스마다 필요한 대상만 그린다. 현재 전체 장면을 반복 렌더링하는 부분을 줄일 후보다. 교각·바위처럼 양쪽에 걸친 것은 별도로 처리하고 투명 지느러미·수면 경계의 누락을 검증해야 한다.
- 원본의 수면 파문은 256² GPU 높이장으로 전파·감쇠하고, 연잎 등도 같은 높이를 사용한다. 이는 현재 해석적 파문보다 연동성은 좋지만 매 프레임 추가 GPU 패스가 필요하므로 1차 성능 개선과 함께 무조건 넣지 않는다.
- 원본의 수중 빛무늬는 직접광에 반영된다. 현재 일부 재질의 발광에 더하는 표현을 조명 기반으로 옮기면 그늘에서 스스로 빛나는 느낌을 줄일 수 있다.

소스: [수면 시뮬레이션·광학](https://github.com/souranyp-stack/koi-pond-garden/blob/18213ec590e987f605cce6564471e6c0f9451d37/koi-pond.html#L4948-L5334), [패스와 레이어](https://github.com/souranyp-stack/koi-pond-garden/blob/18213ec590e987f605cce6564471e6c0f9451d37/koi-pond.html#L5336-L5402), [수중 조명](https://github.com/souranyp-stack/koi-pond-garden/blob/18213ec590e987f605cce6564471e6c0f9451d37/koi-pond.html#L1228-L1380).

## 적용 순서와 검증

1. **정원 구성:** 대표 나무 수형 분리 + 물가 관목·고사리·붓꽃 군락. 기존 카메라로 전경·수면 높이·전체 조감도를 비교.
2. **불필요한 패스 제거:** 수상/수중 레이어. 동일 해상도·카메라에서 드로콜·삼각형·프레임 시간 측정, 경계 물체 누락 검사.
3. **생물 움직임:** 추진·활주·깊이 기반 회피, 물방울의 이벤트 연결. 장시간 유영과 먹이 반응 확인.
4. **물 광학:** 깊이 굴절과 흡수. 정면·비스듬한 수면·얕은 물가·물고기 근접 시 색과 윤곽 비교.
5. **선택적 고급 효과:** 공유 파문 높이장, 수중 뿌리·줄기, 추가 동물. 앞 단계의 GPU 여유를 측정한 후 결정.

원본의 SSAO·다중 블러·DoF·갓레이 전체를 이식하는 것은 우선순위가 낮다. 현재 숨김/정지 시 렌더링을 멈추는 수명주기는 유지한다. 원본의 재질 패치는 Three r160 내부 셰이더 문자열에 의존하므로 현재 r186에 복사 적용하지 않고 사용 중인 셰이더 구조에 맞춰 옮긴다.

이 분석은 성능 향상 수치를 보장하지 않는다. 다음 구현에서 같은 해상도·품질 설정·카메라 경로로 변경 전후를 측정하고, 자동 해상도 하향을 성능 개선으로 집계하지 않는다.

## 2026-09-30 적용: 식생과 유영

- `planting.ts`: 새로 작성한 절차적 형상. 9개 기존 나무 위치를 보존하며 활엽수·단풍·벚꽃·소나무의 가지/잎을 분리. 26개 관목 내부와 표면 잎, 고사리·무늬 잎·붓꽃 군락을 추가했다. 외부 코드를 복사하지 않았으며 미술 방향의 참고는 파일 주석과 이 문서에 기록했다.
- 풀 78,000→56,000, 잎/꽃/하층 식물 인스턴스 44,852→26,078. 원경·바닥 일러스트, 생물/건축 GLB, 조명과 물의 설정을 유지했다. 가까운 식물에는 실제 입체 형상을 사용하며 관목 내부와 고사리의 작은 텍스처는 초기화 시 생성한다.
- 새 바람 변형은 GPU에서 처리하며 수관 그림자에도 같은 변형을 사용한다. 새 깊이 재질의 해제를 장면 dispose에 포함했다.
- `fish-motion.ts`, `koi.ts`: 개별 추진/활주 주기, 연속적인 속도·꼬리 진폭 전환, 크기에 따른 꼬리 속도. 깊이가 다른 개체는 불필요한 평면 회피에서 제외. 모델·색·크기·개체 수는 그대로다.
- 로컬 IAB 1280×720, 동일 초기 Garden 카메라에서 renderer.info 마지막 메인 패스 집계: 삼각형 2,118,839→2,034,373(-3.99%), calls168→178. 전체 수면/그림자 패스 합계나 실측 GPU 시간은 아니다. 캡처 시뮬레이션 시간은 달라 움직이는 생물의 픽셀 비교에는 사용하지 않는다. 증거 `docs/validation/pond-planting/` (git 제외).
- 검증: 연못 테스트 10개(2분 유영 경계/연속성, 추진·활주 독립성, 개구리 포즈, 나비 착지, 지면 경계) 및 strict TypeScript/Vite 빌드 통과. 브라우저 셰이더/콘솔 오류 없음.
- 깊이 기반 물 광학·렌더 레이어·추가 수면 파티클은 이번 구현에 포함하지 않았다.
