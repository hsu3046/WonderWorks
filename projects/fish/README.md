# Ocean Shoal · WebGPU

6,144마리 물고기가 수중에서 유영하는 독립 작품. [참조 사이트](https://threejs-fish.vercel.app/)와 사용자 녹화를 바탕으로 새로 작성했습니다. 물고기·바위·해초·수면·굴절광은 코드로 생성하며 외부 모델, 이미지, API를 사용하지 않습니다.

## 실행

Node.js와 WebGPU 지원 브라우저가 필요합니다.

```sh
cd projects/fish
npm ci
npm run dev
```

[로컬 미리보기](http://127.0.0.1:4174/). 기존 비눗방울 작품의 4173 포트와 분리합니다.

```sh
npm run check   # 엄격한 TypeScript 검사
npm run build   # dist/ 정적 빌드
npm run preview
```

빌드 결과를 HTTPS 정적 호스트에 올릴 수 있습니다. WebGPU는 HTTPS 또는 localhost가 필요합니다. WebGL로 대체 실행하지 않으며 GPU 초기화 실패 시 설명과 다시 불러오기 버튼을 표시합니다.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 휠 / 트랙패드 스크롤 | 줌인·줌아웃 |
| 포인터 이동 | 포인터 광선 근처의 물고기를 밀어냄 |
| 클릭·탭 | 확장하는 충격파 |
| 드래그 | 자동 카메라를 인계받아 둘러보기 |
| 두 손가락 핀치 | 줌, 구현됨·실기 확인 필요 |
| ＋ / − | 키보드 줌 |
| C / 패널의 Auto camera | 자동 카메라 켜기·끄기 |
| R | 기본 수동 시점 복귀 |
| Space | 시뮬레이션·렌더 일시정지/재개 |
| H | 설명과 설정 패널 숨기기/보이기 |

오른쪽 위 패널에서 빛줄기·굴절광·안개·유영 속도·밝기를 조절합니다. 참조 녹화에는 패널 내부가 보이지 않아 이 항목들은 재현본에서 정한 구성입니다.

기본 설정: Light rays 1.6 · Caustics 1.35 · Water haze 0.032 · Swim speed 2.0 · Exposure 0.95. 사용자 스크린샷의 슬라이더 위치로 환산한 값입니다. 화면 문구는 영어입니다.

## 구조와 한계

- Three.js 0.186.0 WebGPURenderer, TSL + WGSL, TypeScript strict, Vite.
- GPU 버퍼에 위치와 속도를 저장하고, 이웃 32개 샘플 + 유영장으로 방향을 계산합니다. 속도 계산과 위치 갱신을 두 dispatch로 분리합니다.
- 단일 InstancedMesh로 물고기를 그리며 꼬리 운동·회전 시 기울기도 GPU에서 계산합니다. 독립적인 반경/축방향 분포, 회전축 변화와 세 그룹의 분리·재결합으로 군집 부피가 변합니다.
- 자동 카메라는 기본 OFF이며 C로 켭니다. 56초 경로로 낮은 시점·수면·측면·군집 내부·후퇴를 연결합니다. 휠/드래그 시 현재 위치를 이어받으며 C로 재개합니다. 모든 환경에서 수동 카메라로 시작합니다.
- 선형 HDR 장면에 깊이 기반 볼륨광(절반 해상도, 20샘플)과 Bloom을 합성한 뒤 최종 톤매핑/색 변환을 한 번만 적용합니다.
- 휠은 카메라 거리를 2.5~55로 제한하고 시간 기반으로 부드럽게 보간합니다.
- 렌더 버퍼는 최대 약 180만 픽셀, DPR 1.5로 제한합니다. 숨김·일시정지 시 프레임 루프를 중단하도록 구성합니다.
- 원본 소스가 없는 영상 기반 재구현입니다. 원본과 동일한 알고리즘·궤적·픽셀 결과를 보장하지 않습니다. 집광 무늬와 빛줄기는 실시간 근사입니다.
